# Решения

Здесь записано, почему сделано так и от чего уже отказались. Прежде чем предлагать изменение, проверь этот список. Чтобы пересмотреть решение, добавь новую запись, а старую не удаляй.

Формат: **решение** — причина (дата / версия).

## Платформа и данные

- **PWA вместо нативного приложения.** Нужно быстро проверить идею, пользователь один, данные локальные. Нативное приложение — когда идея подтвердится. (22.10, v1)
- **Данные только в `localStorage`, резервная копия JSON-файлом.** Без сервера и аккаунтов. iOS может очистить данные веб-приложения, поэтому копию делают вручную. Данные PWA с экрана «Домой» отделены от Safari. (v1)
- **Без внешних библиотек и CDN.** Один самодостаточный файл: работает офлайн, проще поддерживать. (v1)
- **Календарный месяц, без переноса остатка или перерасхода.** (v1)
- **Общий бюджет — отдельное число, а не сумма лимитов.** Лимиты есть не у всех категорий. (v1)
- **Лимиты и бюджет действуют с месяца, в котором заданы, и дальше; прошлые месяцы не меняются.** (v1)
- **Только рубли, только целые суммы.** Копейки на практике не нужны; запятую на клавиатуре заменила ✓. (v8)

## Цвет и главный экран

- **Категории красятся только по состоянию: серый, зелёный, жёлтый, красный. Своих цветов у категорий нет.** Цвет должен сразу показывать проблему. Выбор цвета категории убран. (v4, подтверждено в v6)
- **Жёлтый — темп 100–120 %, красный — больше 120 % или перерасход; первые дни месяца считаются как 12 % лимита.** Без буфера одна покупка 2-го числа красит категорию в красный. (v1, v4)
- **Подсветка темпа отключаемая, по умолчанию выключена.** Когда она выключена, красным выделяется только перерасход. (v1, v4)
- **Разовые категории (ЖКУ, подписки) красятся только при перерасходе.** На 10-е число ЖКУ всегда «быстрее темпа». (v1)
- **Категории без лимита: серый без трат, зелёный при тратах, красными не бывают.** (v4)
- **Карточка бюджета не красится по состоянию:** заливка всегда тёмно-зелёная, при перерасходе карточка розовая. (v4, v6)
- **Карточка бюджета — «уровень» с заливкой остатка, без отметок «где должен быть уровень сегодня».** Оранжевые отметки из макета убрали как лишние. (v6)
- **Плитки категорий в 2 столбца, иконка перед названием (вариант «Б»).** Сравнивали три варианта: без иконок, иконка перед названием, иконка в углу. (v6)
- **Перетаскивается вся карточка бюджета, а не кружок.** (v6)
- **Нижняя панель — «холм» во всю ширину, а не круглая кнопка.** Она уравновешивает шапку. (v2, оставлено в v6)
- **Экран без прокрутки, прокручивается только сетка.** (v2)
- **Свайпа между месяцами нет, только стрелки.** Добавили в v2, убрали в v4 по желанию пользователя.
- **Размытие под Dynamic Island — системный эффект iOS 26.** Шапку опустили на 14 px, ниже опускать не стали. (v4–v5)
- **Статус-бар не перекрашиваем, когда открыта шторка.** Попытка через `theme-color` сделала хуже и откачена. (v4 → v5)

## Ввод траты

- **Своя клавиатура вместо системной.** Системная перекрывала поле суммы, страница прыгала, появлялась панель AutoFill, которую сайт убрать не может. (v3)
- **Раскладка телефонная, 3 ряда + правый столбец ✓ / 0 / ⌫.** Сравнивали плоские варианты в 2 ряда. (v3, v8)
- **Запись — клавишей ✓, отдельной кнопки нет, название категории в кнопку не пишется.** (v8)
- **Выбор категории только выбирает её, а не сохраняет трату.** Раньше нажатие на категорию сразу записывало трату, это было неявно. (v4)
- **Категории в форме — плоские нейтральные чипсы со скроллом вбок, без цветов и иконок.** (v7)
- **Дата — барабан прямо в кнопке, клавиатура остаётся на месте.** Было колесо на месте клавиатуры с «Готово» — лишний шаг. Краешек «Вчера» подсказывает, что барабан крутится. (v4 → v5)
- **В барабане 5 дней прошлого месяца.** Чтобы 1-го числа записать трату за 31-е. (v4)
- **Нет крестиков ни в одном окне;** закрытие свайпом вниз, по затемнению или Esc. (v5)
- **Заголовок формы: «Потрачено → Категория», без иконки.** (v5, v8)

## Сохранение

- **Анимация по PRD «Анимация сохранения траты»:** шторка уезжает, затем меняются цифры на главной, пульс и вспышка плитки. Данные пишутся сразу. (v9)
- **Вибрации нет.** У веб-приложений на iOS нет доступа к вибрации. Обходной путь через скрытый системный переключатель (iOS 18+) на устройстве не сработал и удалён. (v9 → v10)
- **Тост светлый, на месте названия месяца, и только когда изменение не видно:** другая дата месяца или плитка за краем. Тёмная пилюля у Dynamic Island терялась. (v9)
- **Кнопки «Отменить» в тосте нет.** Ошибочную трату удаляют через историю. (v9)
- **После правки траты из истории возвращаемся на главную**, а не в историю: так видна анимация изменения. (v9)

## Теги

Основа — PRD «Теги для трат».
- **Теги общие для всех категорий, до 15, название до 14 символов, без цветов.** Цвета тегов не нужны, цветная точка хуже читается как «тег». (v11)
- **Кнопка тега в колонке с датой (144 px), меню 200 px.** Кнопка 128 px вмещала около 60 px названия; меню шириной с кнопку — около 11 символов при лимите 14. (v11)
- **Теги — не полоса чипсов, как категории.** Перегружает форму. (v11)
- **Порядок тегов — перетаскиванием за ≡ с автопрокруткой, а не стрелками.** Стрелки медленные для длинного списка. (v11)
- **Удаление тега — корзиной с подтверждением, не свайпом.** Свайп неочевиден. (v11)
- **Нажатие вне меню тегов закрывает его и сразу выполняет своё действие.** Открытый вопрос PRD, принято «да». (v11)
- **Страница тегов — полноэкранная, выезжает справа;** из формы открывается поверх неё с сохранением всего введённого. (v11)
- **Заголовок «Теги · n/15».** (v11)
- **При удалении категории теги остаются.** (v11)
- **Теги в истории и аналитике — следующий этап.** (v11)

## Процесс

- **Спецификация, решения и история — в репозитории рядом с кодом;** скриншоты генерируются скриптом из кода. Так работу можно продолжать без контекста конкретного чата. (v12)
