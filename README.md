# Месячный бюджет — PWA

Одна страница: общий бюджет на месяц и бюджеты по категориям. Работает офлайн, данные хранятся только на телефоне.

## Как поставить на iPhone (10 минут)

1. Зарегистрируйтесь на github.com, создайте **публичный** репозиторий, например `budget`.
2. Загрузите в него все файлы из этой папки (Add file → Upload files).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/budget/`.
5. Откройте адрес **в Safari** на iPhone → «Поделиться» → «На экран „Домой“».
6. Запускайте с иконки. Данные приложения с иконки и данные во вкладке Safari — разные хранилища.

Альтернатива без Git: Netlify Drop (app.netlify.com/drop) — перетащить папку в браузер.

### Обновление
После правок в `index.html` поменяйте `VERSION` в `sw.js` (например `v2`), загрузите файлы заново и перезапустите приложение на телефоне (иногда дважды).

### Бэкап
Настройки → «Сохранить копию данных» → «Сохранить в Файлы». Восстановление: «Загрузить копию». Делайте копию раз в пару недель: iOS теоретически может очистить данные веб-приложения.

## Что умеет страница (v1)

Экран подстраивается под высоту телефона и не прокручивается целиком.

**Шапка.** Месяц по центру со стрелками ‹ › по бокам, справа кнопка настроек. Дальше текущего месяца уйти нельзя.

**Карточка бюджета — «уровень».** Тёмно-зелёная заливка показывает остаток бюджета: в начале месяца закрывает всю карточку и опускается по мере трат. Текст на заливке белый, на светлой части тёмный. В карточке подпись «Осталось», крупно остаток, строка «потрачено N ₽ из M ₽» и подсказка. При перерасходе карточка розовая: «Перерасход», красное «−N ₽». Если бюджет не задан, карточка светлая с суммой трат. Вся карточка — источник перетаскивания: зажать и тянуть на плитку категории. Короткое нажатие открывает ввод траты.

**Плитки категорий** (2 в ряд). Иконка и название, сумма трат и «/ лимит», ниже полоска заполнения. При перерасходе сумма красная и рядом «+N ₽». Без лимита — только сумма, без полоски. Цвет иконки и полоски зависит от состояния:
- серый — трат нет;
- зелёный — траты есть, темп в норме (у категорий без лимита — всегда при тратах);
- жёлтый — тратится чуть быстрее месяца (до 120% от «положенного»), только при включённой подсветке темпа;
- красный — заметно быстрее (больше 120%) или перерасход лимита.

Если подсветка темпа выключена: серый / зелёный / красный только при перерасходе. Разовые категории красятся красным только при перерасходе. Последняя плитка «+ Категория». Если категорий много, прокручивается только сетка.

**Нижняя панель** во всю ширину с подъёмом к центру и «+»: нажатие в любом месте открывает ввод траты.

**Ввод траты.** Заголовок «Потрачено → категория» (текстом, без иконки). Строка: сумма и справа дата-барабан: выбранная дата по центру («Сегодня», «Вчера», дальше «22.10 Чт»), сверху и снизу видны краешки соседних. Ниже комментарий, категории в виде плоских чипсов в 2–3 ряда с прокруткой вбок (нажатие выбирает и подсвечивает зелёным). При выборе чипс докручивается так, чтобы быть видным целиком с отступом; так же при открытии с уже выбранной категорией. Запись — зелёная клавиша ✓ на клавиатуре: серая и неактивная, пока нет суммы или категории.

Перетаскивание карточки бюджета на категорию открывает ту же панель с уже выбранной категорией.

Сумма набирается на своей клавиатуре: 1–9 блоком 3×3, справа столбец «✓» / «0» / «⌫». Удержание «⌫» стирает сумму. До 7 цифр, только целые рубли.

Дата выбирается прокруткой прямо в кнопке: тянешь вниз — более ранние дни, до 1-го числа и ещё 5 дней прошлого месяца. Нажатие на видимый краешек выбирает эту дату. Клавиатура при этом остаётся на месте. Комментарий открывает системную клавиатуру, наша на это время прячется.

**Сохранение траты (анимация).** Нажатие ✓: трата сразу записывается, клавиша пружинит и галочка дорисовывается. Через 170 мс шторка уезжает пружиной (340 мс), затемнение гаснет. После закрытия (510 мс) на главной докручиваются «Осталось» и сумма категории (520 мс), опускается уровень в карточке, дорастает полоска (650 мс), плитка пульсирует (460 мс) и вспыхивает светло-зелёным (1,1 с). Если трата выводит категорию за лимит, красный цвет и «+N ₽» появляются в конце прокрутки. Ничего не блокируется: новая трата сразу останавливает прошлые анимации в итоговых значениях. Изменение траты из списка категории после ✓ возвращает на главную.

**Тост** — светлая плашка на месте названия месяца (месяц на это время скрыт), 3,6 с. После сохранения траты он показывается только если изменение не видно: дата вне открытого месяца или плитка категории пролистана за край. Текст «125 ₽ → Здоровье, сегодня» (или «вчера», «28 сентября», «28 декабря 2025»). В том же стиле остальные уведомления.

При системной настройке «Уменьшить движение» шторка просто затухает, цифры и полоска меняются сразу, остаётся вспышка плитки.

**Теги.** Метки «в рамках чего» поверх категорий (например, «Отпуск на море» объединяет Транспорт, Еду и Подарки). Общие для всех категорий, до 15 штук, название до 14 символов. Совпадение названий проверяется без учёта регистра, лишних пробелов и «ё»/«е».
- В окне ввода справа от комментария кнопка тега (144 px, в одной колонке с датой): «Тег» — нет тегов; название — один тег; первый по порядку и «+N» — несколько.
- Меню (200 px) под кнопкой: теги в порядке из настроек, можно отметить несколько, меню не закрывается между выборами. Внизу «Новый тег» (поле «Название», счётчик n/14, «Такой тег уже есть», плашка «Выбрать «…»», «Добавить») и «Настроить». При 15 тегах «Новый тег» неактивен. Нажатие вне меню закрывает его и сразу выполняет своё действие. Набранный текст сохраняется, если меню закрыть, и пропадает вместе с формой.
- «Настроить» открывает страницу тегов поверх формы, «назад» возвращает в форму со всем введённым и снова открывает меню.
- Страница «Теги · n/15» — из «Настройки → Теги» или «Настроить»: порядок перетаскиванием за ≡ с автопрокруткой у краёв (или стрелками с клавиатуры), переименование (название или карандаш → поле с «Готово»), удаление с подтверждением снизу и тостом «Тег удалён» (тег снимается со всех трат, траты остаются), «+ Добавить».
- Теги меняются и у сохранённой траты. В истории трат и аналитике их пока нет.
- Когда открывается клавиатура iOS, шторка и страница поднимаются над ней.

Все окна закрываются свайпом вниз за полоску или заголовок либо нажатием на затемнённую часть экрана. Крестиков нет.

**Тап по категории** → список трат за месяц по дням, «Добавить трату», карандаш — настройки категории. Тап по трате → «Изменить расход»: ✓ сохраняет, корзина в заголовке удаляет (подтверждение вторым нажатием).

**Настройка категории.** Название, лимит (пусто = без лимита), тип «равномерно / разовый платёж», иконка, удаление вместе с тратами. Разряды в лимите и бюджете разделяются при вводе.

**Лимиты и бюджет** действуют с выбранного месяца и дальше. Прошлые месяцы сохраняют свои значения. Остатки не переносятся.

**Подсветка темпа** (выключена по умолчанию, включается в настройках):
- ожидаемая трата = лимит × (день / дней в месяце), но не меньше 12% лимита;
- темп ≤ 100% — зелёный, до 120% — жёлтый, больше или перерасход — красный;
- разовые категории красятся только при перерасходе.

## Данные

`localStorage`, ключ `monthly-budget-v1`:

```json
{
  "budget": { "2026-10": 150000 },
  "categories": [{ "id": "…", "name": "Продукты", "icon": "shopping-cart", "color": "#C2577A",
                   "type": "even", "created": "2026-10", "limits": { "2026-10": 30000 } }],
  "tx": [{ "id": "…", "cat": "…", "amount": 1200, "date": "2026-10-22", "comment": "Магнит", "tags": ["…"] }],
  "tags": [{ "id": "…", "name": "Отпуск на море" }],
  "settings": { "pace": false }
}
```

В `limits` хранится значение с месяца, с которого оно действует; `null` — без лимита. Порядок тегов — порядок массива `tags`.
